# ⚙️ Environment Configuration

Create `.env`

```env
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587

SENDER_EMAIL=your-email@gmail.com
APP_PASSWORD=your-app-password

RECEIVER_EMAIL=receiver@gmail.com
```
